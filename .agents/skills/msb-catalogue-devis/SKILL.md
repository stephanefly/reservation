# Devis / catalogue MySelfieBooth
1. Lire `docs/catalogue-commercial.md` et `docs/admin-devis-auto.md` ; ne pas s'appuyer uniquement sur `docs/devis-instantane.md`, historique.
2. Catalogue /backend/catalogue/ = offres actives et prix de référence. Le calcul manuel ou PDF, les options historiques et le 3 h peuvent utiliser une autre grille. Ne pas supposer que modifier l'un synchronise tous les autres.
3. Devis automatiques : module et catalogue désactivés par défaut jusqu'à activation staff, offres éligibles explicitement ; recommandations et entreprises restent manuelles ; source admise, durée 3/5 h, pack exact, code postal cohérent et plancher 350 €.
4. Sans validation, ne jamais envoyer, encaisser ni signer automatiquement ; la simulation doit rester sans mutation.
5. Prix de référence (à revalider) : Photobooth 400 €/5h ; Miroir 500 €/5h ; 360 450 €/5h ; Vogue seul 550 €/5h. Packs de référence : Souvenirs 600, Immersion 360 700, Signature 800, Duo VIP 850, Vogue Premium 700, Mariage Prestige 1200 €.
6. Distinguer Vogue seul / pack avec photographe et impression ; Phonebooth audio / livre d'or vidéo ; panneaux XXL selon barème quantité documenté.
7. Lors d'un changement de prix, vérifier écran public, formulaire, simulation, PDF, options, tests et historique, puis documenter les différences restant à harmoniser.
