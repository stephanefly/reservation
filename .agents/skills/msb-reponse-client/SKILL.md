# Relation client
1. Identifier particulier / entreprise / partenariat ; vérifier le dossier CRM si accessible avec l'autorisation adéquate.
2. Reprendre les contraintes déjà données : date, horaires, lieu, machines, options, impressions, présence d'animateur, accès. Ne demander que les informations réellement manquantes.
3. Distinguer les appareils et les souvenirs produits ; vérifier les options et prix dans le catalogue actif avant de rédiger.
4. Entreprise : devis manuel, sans acompte ; recommandation : traitement manuel. Pas d'affirmation « réservé », « envoyé », « signé » ou « disponible » sans état vérifié.
5. Rédiger une réponse française concise, professionnelle, factuelle et sans emoji. Renvoyer vers https://reservation.myselfiebooth-paris.fr/ pour la qualification si utile.
6. Si l'utilisateur n'a demandé qu'une rédaction, fournir un brouillon, sans l'envoyer. Exiger une action autorisée et un résultat de l'outil avant d'annoncer un envoi.
7. Contrôler destinataire, montant, TVA, date, matériel et signature avant livraison.
